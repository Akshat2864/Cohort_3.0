Browser Rendering Pipeline

HTML Path

HTML
📄
Raw HTML Bytes
Browser receives bytes from the server over the network.
↓
Step 1
🔤
Tokenization
HTML is broken into tokens: start tags, end tags, attributes, text nodes.
↓
Step 2
🧩
Parsing
The parser processes tokens and constructs objects, following the HTML5 spec state machine.
↓
DOM Tree
🌳
DOM Tree
A tree of Node objects — Document → html → head/body → children. JS can query and mutate this.

CSS Path

CSS
🎨
Raw CSS Bytes
Stylesheets fetched from <link> tags or inline <style> blocks.
↓
Step 1
🔤
Tokenization
CSS source is tokenized into selectors, properties, values, and rules.
↓
Step 2
🧩
Parsing
CSS tokens are parsed into a structured object model of rules and declarations.
↓
CSSOM
🎭
CSSOM Tree
CSS Object Model: a tree of style rules with computed values, specificity, and cascade resolved.
DOM Tree + CSSOM Tree
↓
Render Tree
Render Tree
The browser combines the DOM and CSSOM into a Render Tree containing only visible nodes with their computed styles. Nodes with display:none are excluded. This tree is used for Layout (geometry calculation) → Paint (pixel drawing) → Composite (layer merging).
Step 3
📐
Layout (Reflow)
Browser computes exact position and size of every element in the viewport.
Step 4
🖌
Paint (Repaint)
Pixels are drawn into layers: text, backgrounds, borders, shadows, images.
Step 5
🖥
Composite
Layers are merged in correct order and the final frame is displayed on screen.
